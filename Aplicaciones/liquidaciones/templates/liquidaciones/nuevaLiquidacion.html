El sistema calcula cada pago según el primer día de entrega de cada proveedor.

1. Fecha de cierre

Se genera un día antes de cumplirse cada mes desde la primera recepción.

2. Recepciones incluidas

El corte se realiza dos días antes para respetar el plazo de clasificación.

3. Documento y pago

Primero se entrega el reporte; después se carga el documento y se habilita el pago.

Cada clasificación se liquida una sola vez. Las entregas posteriores al corte pasan al siguiente ciclo.
